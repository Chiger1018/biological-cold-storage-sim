# 巨型生物体冷链入库流程仿真与校验系统
## Simulation and Verification System for Cold Chain Warehousing Process of Giant Organisms

> 【趣味C语言练手项目】
> 形而上化包装，外表硬核高大上，内核是经典脑筋急转弯：**把大象放进冰箱一共几步**
> 含水量极高的演示项目，仅供娱乐与C语言基础练习，无任何实际冷链业务功能。

### 📖 项目介绍
本程序是交互式控制台答题系统，包含3轮连环脑筋急转弯：
1. 将大象存入冰箱需要几步
2. 将长颈鹿存入冰箱需要几步
3. 森林大会，谁缺席？

### ✨ 功能
- 控制台交互输入
- 字符串匹配判断答案（`strcmp/strstr`）
- 文字提示反馈
- 趣味结尾致谢
